# Домашнее задание 14 — Позиционирование элементов и z-index

## Задания

### Задание 1: Связка relative + absolute для бейджа (10 б.)
Карточка товара имеет `position: relative`, бейдж "NEW" — `position: absolute; top: 12px; right: 12px`. Благодаря этому бейдж позиционируется относительно карточки, а не всей страницы.

### Задание 2: Плавающая шапка position: fixed (12 б.)
Шапка сайта закреплена через `position: fixed; top: 0; left: 0; right: 0`. Основному контенту задан `padding-top: 80px`, чтобы он не заезжал под шапку при скролле. `z-index: 50` держит шапку над контентом, но ниже модального окна.

### Задание 3: Модальное окно с оверлеем (12 б.)
Оверлей — `position: fixed; inset: 0; z-index: 100`, затемняет фон. Окно центрируется через `top: 50%; left: 50%; transform: translate(-50%, -50%)` (в проекте использован flex-центринг внутри оверлея как современная альтернатива) и имеет `z-index: 101`, поэтому всегда поверх шапки. Открытие/закрытие — на JS по клику и по клику на оверлей.

## Технологии
- HTML5
- CSS3 (position, z-index, transform)
- Vanilla JavaScript

## Выводы
`position: absolute` работает относительно ближайшего позиционированного предка, поэтому связка `relative` + `absolute` — стандартный паттерн для бейджей. `position: fixed` привязывает элемент к viewport, что идеально для плавающей шапки, но требует компенсации отступа у контента. `z-index` управляет порядком наложения только у позиционированных элементов, поэтому важно правильно выстроить иерархию слоёв: контент → шапка → оверлей → модальное окно.
